# Lab 03 – Apache Shellshock Exploitation

## Overview

This lab demonstrates a complete penetration testing engagement against a vulnerable Ubuntu server running Apache 2.2.22 with a CGI application vulnerable to the Shellshock vulnerability (CVE-2014-6271).

The assessment follows a standard penetration testing methodology, including reconnaissance, service enumeration, vulnerability assessment, exploitation, post-exploitation, and privilege escalation.

---

## Objectives

- Discover the target host
- Enumerate running services
- Identify vulnerable software versions
- Verify the Shellshock vulnerability
- Gain remote command execution
- Perform post-exploitation enumeration
- Escalate privileges to root
- Document all findings professionally

---

## Target Environment

| Item | Details |
|------|---------|
| Operating System | Ubuntu 12.04 |
| Web Server | Apache 2.2.22 |
| Vulnerability | Shellshock (CVE-2014-6271) |
| Initial Access | www-data |
| Final Privilege | root |
